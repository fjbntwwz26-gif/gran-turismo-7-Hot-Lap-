About

An unofficial Gran Turismo 7 friends leaderboard. Lap times are ranked fastest first for the selected track and car.

🏁 RACE SET UP INSTRUCTIONS 🏁

When setting up your Time Trial in GT7:

  • Go to World Circuits → Asia-Oceania → Tokyo Expressway.
  • Select South Clockwise → Time Trial.
  • Choose Twilight if the time-of-day setting is available.
  • 3 Laps Maximum → Change Driver
